◆ clearInsertBlock()

void mir::MirBuilder::clearInsertBlock ( )
inline

Clears the insert block for this builder. When the insert block is cleared, creating instructions will throw a fatal error.

Note
If you want to clear the insert block without asserting when adding instructions, it is recommended to maintain a temporary discard block and set that as the insert block instead of clearing it.
