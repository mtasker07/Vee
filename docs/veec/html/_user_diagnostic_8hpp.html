Detailed Description

This file contains the definition of the UserDiagnostic struct.

The user diagnostic represents a diagnostic message that should be displayed to the user, such as an error or warning.

Note
It's important that the user diagnostic is not used for internal diagnostics. Instead use the internal error handling system in vee/core/InternalErrorHandling.hpp. Specifically: VEE_FATAL(), VEE_ASSERT(), VEE_UNREACHABLE()...
