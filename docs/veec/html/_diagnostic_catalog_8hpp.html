Detailed Description

This file contains the diagnostic catalog for the VEE compiler.

The diagnostic catalog represents a collection of diagnostic messages that can be displayed to the user, such as errors or warnings.

Descriptors should all be in the same format:

  • MUST be inline constexpr
  • MUST be of type DiagnosticDescriptor<ArgCount> where ArgCount is the number of arguments to format into the message template.
  • MUST have a unique code for its specific kind. E.g. error codes can overlap with warning codes, but not with other error codes. For everything else just take a look at the existing descriptors and follow the same format.

Its important to note that the diagnostic catalog is not intended to be used for internal diagnostics.
