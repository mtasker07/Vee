Detailed Description

template<typename T, size_t N = 4, class Allocator = std::allocator<T>>
class basic::SmallVector< T, N, Allocator >

Represents a small vector of type T. A SmallVector can store a small number of elements inline and dynamically allocate memory for larger sizes, making it more efficient for small sizes.

Template Parameters
TThe type of elements stored in the SmallVector.
NThe number of elements that can be stored inline (default 4).
AllocatorThe allocator used for allocating internal objects (default std::allocator<T>).
