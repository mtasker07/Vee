Detailed Description

template<typename T = Symbol>
class symbols::SymbolHandle< T >

Represents a handle to a symbol, which may or may not be resolved. A symbol handle can be resolved to a specific symbol during semantic analysis.

Template Parameters
TThe type of symbol this handle refers to, which must be derived from Symbol.
Note
If T is not specified, it defaults to Symbol (which can be any symbol type).
